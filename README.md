# Kayden’s Crew

A kid-safe Incredibox-style music mixer for Kayden Spartano.

- Mixed roster: space, animals, weird-cute, friend & pet sounds
- Drag sounds onto the stage to layer loops
- Rename friend/pet sounds to match real people and pets
- No Sprunki characters and no horror mode

## Play

- **GitHub Pages:** https://dspartan8.github.io/kaydens-crew/
- Open `index.html` locally, or any static file server from the repo root

## Enable GitHub Pages (one-time)

1. Repo **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: **main** / folder: **/ (root)**
4. Save — site appears at the URL above after a minute or two

Static site only — no secrets, no backend.
